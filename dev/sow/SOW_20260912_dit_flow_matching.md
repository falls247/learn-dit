# SOW：DiT・Flow Matching実践教材の開発

- 作成日：2026-09-12
- 状態：実装前の提案差分。実装状況は検証記録で別途管理する。

## 1. 目的

GR00T N1.7の動作生成部分を理解するため、公開データを用いた小型DiTの学習・推論・結果確認を体験できる教材を開発する。対象はPython経験があり、学習実装は初めての利用者。MNISTの画像生成からPushTの観測条件付き動作生成へ進む。

## 2. 範囲

PythonスクリプトとCLI、データ取得・前処理、DiTとFlow Matching、保存・再開、可視化、シミュレーション評価、日本語教材、テストを実装する。GR00T本体、実機、言語条件、有料クラウド、学習済みモデル配布、DDPM比較、Notebook、Web UIは対象外。

## 3. 技術仕様

Python 3.12とuv、PyTorchを使用する。対象GPUはRTX 4070 Ti SUPER。CUDA Toolkitの自動更新は行わない。GPU診断とCPUスモークテストを提供する。

MNISTはtorchvisionから取得し、公式学習データをseed 42で55,000件の学習用と5,000件の検証用に分割する。画素は[-1,1]へ変換する。

PushTはlerobot/pushtの206エピソードを使用し、取得リビジョンを記録する。seed 42で185エピソードを学習用、21を検証用に分割する。動画と位置・動作を時刻で対応付ける。正規化統計は学習データだけから算出する。系列はエピソード境界をまたがず、履歴不足は先頭観測で補い、未来不足は損失マスクで除外する。

共通DiTは4ブロック、隠れ次元128、4ヘッド。位置情報、Self-Attention、時刻のAdaLNを実装する。Flow Matchingは ε~N(0,I)、t~Uniform(0,1)、x_t=(1-t)ε+tx、目標速度x-εのMSEを使用する。Euler法でt=0から1へ生成し、標準32ステップ、比較用4・8・16・32ステップを提供する。

MNISTは28×28画像を4×4パッチへ分割し、数字ラベルで条件付けする。VAEは使用しない。PushTは直近2時点の96×96画像と2次元位置を入力し、小型CNNと位置特徴をCross-Attentionで参照する。未来16ステップの2次元目標位置を生成し、先頭8ステップを実行して再観測する。

学習初期値はAdamW、学習率1e-4、バッチサイズ128、seed 42。時間上限は1,800秒で、取得・前処理・学習後評価を含めない。更新ステップ間で時間を確認し、保存による超過は許容する。モデル、Optimizer、学習ステップ、乱数状態、設定、正規化情報を保存し、通常中断と再開に対応する。

## 4. インターフェース

`uv run learn-dit`配下にdoctor、prepare、inspect、train、sample、evaluateを用意する。題材は`--task mnist`または`--task pusht`。生成・評価は`--checkpoint`、再開は`train --resume`で指定する。

実験ごとに設定、ログ、チェックポイント、評価JSON、損失曲線、生成画像、生成途中経過を保存する。PushTは軌跡とMP4も保存する。

## 6. 実装順序

1. 環境診断、CLI、設定管理。
2. MNIST取得と1バッチの学習解説。
3. 共通DiT、Flow Matching、保存・再開。
4. MNIST学習・生成・可視化。
5. PushT前処理、条件付け、動作生成。
6. シミュレーション評価と動画出力。
7. GPU実測、教材、ADR、検証結果。

## 7. 受入条件

- 補間端点、速度符号、Euler更新、正規化往復、時刻対応、分割独立性、系列マスクを検証する。
- 少数サンプルで損失低下と重み更新を確認し、保存後の推論と追加学習を検証する。
- MNISTの0〜9条件付き生成と途中経過を保存する。
- PushTで動作を実行し、動画と評価JSONを保存する。
- 未学習・学習後を同じ20個の初期化seedで比較し、成功率、最大到達報酬、推論時間を記録する。
- 公開データ取得から保存モデルの出力まで再実行できる。
- GPU検証、所要時間、未検証事項を報告する。

30分以内の高品質な生成やPushT成功率は保証しない。低成績も記録し、追加学習できることを必須とする。GPUアクセスは未確認であり、検証不能時は未検証として残す。
